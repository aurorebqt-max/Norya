- Le PDF source n'est pas envoyé sur Supabase.
- Aucun OCR d'image n'est inclus : les PDF sans couche texte nécessitent un OCR séparé.

- Le JSON s'édite encore sous forme de texte ; pas encore d'éditeur visuel question par question.
